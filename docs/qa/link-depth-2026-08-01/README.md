### 読み取り［高］

- **旧 `support-systems` の出典（集約ページ list04828）では、カードが約束した
  「住家の緊急の修理」へ到達できない**。一覧が JS の「もっと見る」でページ送りされる
  構造のため、開いた最初の状態の DOM に文字列が存在しない。
  スクロールの多寡ではなく **0 か 1 かの問題**だったので、出典を本文ページ
  （`kiji00372143`）へ寄せた。同ページは完了期限が 0.4 画面ぶん下に出る。
- `evidence`（2.2画面）・`toilet`（2.1画面）・`shelter-hikawa`（1.8画面）が最も深い。
  いずれも「窓口へ電話する」「避難所を確認する」という**行動の直前に要る情報**が、
  2画面ぶんスクロールした先にあった。
- `water` の出典は全長 13,039px（15画面ぶん）。井戸リスト自体は 0.9 画面ぶん下から
  始まるが、5区で60件を超える表が続くため、カードに一覧は載せず
  `sourceLandmark: "◆井戸リスト"` で探す先だけを名指しした。

## 残っている課題［中］

- **`shelter` の出典は市トップのままにした**。「避難所情報」の実体は
  熊本市防災情報ポータル（`city-kumamoto.my.salesforce-sites.com`）で、
  開設状況・所在地・混雑状況つきの避難所一覧がサーバー側で描画されている
  （システム更新時間 2026/8/1 11:14 を確認済み）。ここへ差し替えれば最初の画面に
  答えが出るが、`salesforce-sites.com` は SaaS の共有ドメインであり、
  出典 allowlist（Decision #8）へ個別ホストを足す判断が要る。**運営者の承認待ち**。
- ページ全長は 390px 幅で 13,928px（19カード）。答えを畳んだ状態でも出すことにした
  ぶん伸びている。困りごとで絞り込めば1〜3枚に減るが、全件表示時の長さは今後の観測対象。
