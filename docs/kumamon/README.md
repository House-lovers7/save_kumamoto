## a. 利用条件・禁止事項一覧

出典を「規程」（315536.pdf）「手引き」（315539.pdf）で区別して記載する。原文の言い回しを
極力そのまま引用する。

### 規程（利用規程 第14条 利用者の遵守事項）より

- 「イラスト等の利用が第１条に規定する目的にあることに留意し、その趣旨を損なわないよう十分に注意すること」（第1号）
- 「イラスト等の利用にあたっては、利用許諾を受けた内容に限ること」（第2号）
- 「利用許諾を受けた権利を譲渡、転貸又は承継しないこと」（第3号）
- 著作権者の表示および利用許諾番号を必ず行うこと（第4号。詳細は下記b）
- 「消費者保護等の観点から、責任の所在が明らかとなるよう、利用対象物等には販売者、製造者又は制作者の名称と連絡先を明示すること」（第5号）
- 第三者への製造委託時は許諾数量以上の製造を防ぐ契約と数量管理の徹底（第6号）
- 完成品の写真又はサンプルの提出（第7号）
- 県の売上調査その他の照会への協力（第8号）
- 各種法令の遵守（第9号）
- 第10条（利用許諾の制限）: 法令・公序良俗違反、県の信用・品位を害する、第三者の利益を害する、**特定の個人・団体・法人（県を除く）・商品等の支援・推薦**、政治的・宗教的・思想的主張の表現、風俗営業等への利用、誤認混同のおそれ、くまモンのイメージを損なうおそれ、**イラスト等の著しい変形**、に該当する場合は許諾しない
- 第18条: 利用許諾は独占的な利用権を付与するものではなく、県による利用者・利用対象物等の推奨を意味しない
- 第15条: 利用料は当分の間無料

### 手引き（利用の手引き 315539.pdf）より、原文ベースの禁止事項

**(1) 特定の商品／企業等のおすすめ禁止（P19-20）**
- 「くまモンは公務員です。パッケージや広告等で、特定の商品や企業の応援、紹介、説明等をすることはできません」
- 「特定情報」（商品、商品画像、価格情報/商品情報、企業名/企業ロゴ/企業キャラクター、おすすめ表現）を配置できるエリアを制限
- 手差し・指差し系イラスト（(9)(10)(17)(18)(31)(32)(35)(36)(45)(46)(47)(103)(124)(125)(128)(129)(134)(152)(194)(232)〜(235)(237)〜(240)(247)(295)(296)(344)(348)）は、指を指す/持ちあげる/見つめるようなデザインが「おすすめ」と捉えられやすいため特定情報配置エリアがさらに制限される
- くまモンに特定情報（社名・ロゴ等）を持たせることはNG。一般的なもの（特定できないもの）を持たせるのはOK
- デザインパーツから「覗く」のはOKだが、デザインパーツを「かぶせる」のはNG

**(2) イラストの変形・加工について（P21-22）**
- 「顔パーツの一定範囲内には、デザインパーツを配置できません」
- 「顔パーツ(目、耳、頬、鼻、口、口の周りの白い部分)は、パッケージ等の裁断部分で見切れないように使って下さい」（総柄の端での見切れを除く）
- 「顔パーツのみの利用は、バックが黒の場合のみ認めます」
- 「特定情報などのデザインパーツなどは、くまモンにかからないようにしてください」
- 著作権表示は「スペースの都合等によりやむを得ない場合のみ体にかかることを認めます（**顔への重なりは認められません**）」

**(3) 特定のイメージ付け・性格付けの禁止（P23）**
- 複数の人格を持たせる配置はNG（くまモン2体の会話・キャッチボール等）
- 「性別や年齢などプロフィール（やんちゃな男の子）から想定できない利用はしないでください。また、プロフィールそのものも追加・改変しないでください」（例: 飲酒、喫煙、女性言葉、スカート、お父さんくまモン・くまモンの彼女 等）
- ストーリーを伴う利用禁止（くまモンが何かを食べに行く、他キャラクターと戦う 等）
- 他キャラクターとの親交表現禁止（抱っこ、手つなぎ、握手、くまモンコスチューム等）
- 「他の地域の PR を目的とした利用はしないでください」（九州のPRを含む）

**(4) シルエット利用（P24）**: シルエット利用可指定イラスト（(1)〜(29)）に限り可。色は原則自由（単色・グラデーション・幾何学模様の塗り分け）だが「顔パーツを示す形での着色は認められません」。文字は特定情報を除きシルエットにかかってよい。

**(5) 手描き利用（P24）**: 「イラストどおりに忠実に表現していただくことが条件です。利用者の作風や個性が表現されるような利用は原則認められません」

**(6) 台詞（P25-27）**: モン語（語尾「くま」「モン」）または熊本弁を原則とした4類型（挨拶/くまモン利用商品に関連した熊本県PR/くまモン出動イベント告知/その他一般的表現）のみ。「ネガティブな表現や、特定の人、商品、団体、思想等を推すあるいは批判する表現は認められません」

**(7) 衣装（P28-29）**: 特定団体・企業のキャラクターと誤認される服装は不可。ロゴ入り・企業/団体特定できる制服は原則NG。

**(8) 商品名等への利用（P31-32）**: 「くまモン」を商品名に直接結合不可（例: ×くまモンチョコ→○くまモンのチョコ）、商号への利用は一切不可、「×(かける)」やコラボ等の表現は原則不可。

**(9) デジタルコンテンツ（P16）**: 「アプリ、スタンプ等については、県で戦略的に利用していく観点から新規申請の受付は行っていません」

**(10) キャラクター色・縦横比（P36）**: 「キャラクター「くまモン」の色を変更することはできません。指定色のままか、単色（黒1色など）での利用となります」「縦横比を変更しないようにしてください」

**(11) イラストごとの個別加工可否**: 各イラスト番号ごとに(1)衣装(2)シルエット(3)覗き・見切れ(4)表情の変更(5)物を持つ(6)反転の6項目で○/△/×が個別指定されている（詳細は下記cの候補参照）。原則は「加工・変更等できません」で、個別に認められた範囲でのみ可。

**AI生成・写真利用について（タスク指定項目、確認結果）**
- 「AI生成不可」という直接の文言は、取得した4資料のいずれにも見当たらなかったが、
  特例ページ本体（274852.html、2026-08-01確認）に「AIで作成したイラストはご利用
  できません。」「くまモンの写真はご利用できません。」と明記されている。**確認済み**。
- 写真の可否は申請区分により異なる。「通常の利用許諾申請」（別記様式第6号）は「こちらの手続では、写真のご利用ができません。イラストをご利用ください」（P4）と明記。一方「簡易な利用許諾申請」（別記様式第9号＝今回の届出様式）は「こちらの手続では、写真・イラストのいずれも利用できます」（P4）とあり、写真利用も可能と読める。ただし対象は簡易申請の4類型（下記「特例の適用範囲」未確認事項を参照）。

- サイズの数値指定（フォントサイズ、余白等）は、規程・手引きのいずれにも見当たらなかった。**未確認**。
- 文字色の指定も見当たらなかった。**未確認**。（P36「指定色及び縦横比について」はキャラクター本体

### 重要な差異（要確認事項）

本リポジトリ内の既存ドラフト（`docs/kumamon/ASSETS.md` 20-22行目、`docs/kumamon/notification-draft.md`
27行目）には、コピーライト表記として **「©2010熊本県くまモン#熊本支援」** という文言が
記載されている。しかし、今回確認した規程・手引きの原文では、「＃」以降は**知事が個別に
指定する許諾番号（K〇〇〇〇〇形式）**であり、申請者が任意の文字列（「#熊本支援」等）を
自由に付記できるものではない。今回の届出様式（別記様式第9号＝簡易な利用許諾申請）を
用いる場合は、そもそも許諾番号自体が付与されないため、正しい表記は番号なしの
**「©2010 熊本県くまモン」**（または英語表記「©2010 kumamoto pref. kumamon」）のみと
なる可能性が高い（[中] 規程原文からの推定。実際にどちらの表記が指定されるかは、県から
の利用許諾の回答を待って確定させる必要がある）。この点は既存ドラフトの修正判断に関わる
ため、本ファイルの範囲外として指摘のみ行い、修正はしていない。

**【解消済み注記（2026-08-01追記）】** 上記の指摘は通常規程・手引き（315536/315539）
に基づく推定であり、**震災支援特例には適用されない**。特例ページ本体
（274852.html、2026-08-01 WebFetchで原文確認）に「ご使用されるイラストの周囲に
『©2010熊本県くまモン#熊本支援』又は『©2010kumamoto pref.kumamon#kumamotoshien』と
記載してください。」と明記されており、特例ではページ側の表記が優先される [高]。
既存ドラフト（ASSETS.md / notification-draft.md）の「©2010熊本県くまモン#熊本支援」は
**正しい**ため修正不要。念のため提出メール（email-draft.md）の照会で県に最終確認する。

## c. イラスト候補3点（フッター掲出向け、最終選定は人間が行う）

  KUMAMOTO」の文字、下部に「くまモン募金箱」の文字（(88)は「くまモン募金箱あります」の

- 注記: 県が支援・募金活動向けに用意した専用デザインであり、テーマ適合性は最も高い。

## d. 届出後のデータ入手手順（追加条件の有無）

取得した4資料（規程・記入例・様式・手引き）のいずれにも、**利用許諾後にイラストの完成
データ（PNG/AI等の画像ファイル本体）を県からどのように受け取るか、についての明記は
見当たらなかった。未確認。**

確認できた「許諾後の流れ」は以下のみ（手引きP7、簡易な利用許諾申請の場合はP8）。

> 許諾後、利用許諾書が届くので、許諾書に記載のある許諾番号を物件に表示する。（表示方法
> は、P16、P18参照）
> くまモン利用許諾事務局に完成品の写真（又は完成品のサンプル）を提出する。

> （簡易な利用許諾申請の場合）許諾後、くまモン利用許諾事務局等から連絡があります。その後、
> ご利用ください。

この記述から、運用の実態は「県が高解像度の元データを配布する」のではなく、**申請者が
手引きのカタログ画像を参考に自らデザイン案を作成し、それを申請時に添付・提出する**方式
である可能性が高い（[中] 添付書類リストに「イラスト等利用状況写真貼付用紙」「具体的な
デザイン案画像の添付が必要」との記載があることから推定。P9-P10参照）。ただし、これは
推測であり、届出書提出後に県から追加のデータ提供案内があるかどうかは資料からは断定
できないため、**未確認**として扱う。
