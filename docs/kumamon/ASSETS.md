# くまモンイラスト アセット管理

## 依頼するデータ

- イラスト番号: [候補選定後に記入]（候補は README.md 参照）
- 形式: PNG（透過）を第一希望
- 依頼方法: 届出受理の確認後、くまモン課（kumamon@pref.kumamoto.lg.jp）へ番号+形式をメール（external_send・人間が送信）

## 受領後の配置ルール（Phase B 実装指示の要約）

- 配置先: `public/kumamon/no-<番号>-v1.png`（ファイル名に番号とバージョンを含める）
- 差し替え時: **同名上書き禁止**。ファイル名を変え、`public/sw.js` の `CACHE` バージョンを上げる（cache-first のため旧ファイルが残り続ける）
- `public/sw.js` の `SHELL` 配列には**追加しない**（addAll が1件でも404するとPWAインストール全体が壊れる）
- サイズ: 表示幅240px想定・480px幅で書き出し・gzip前60KB以下目標
- **リポジトリへのコミットは県の回答（G4）まで禁止**。それまで `.gitignore` に `/public/kumamon/` を追加し、配信物にのみ含める
- 再現性担保: `scripts/qa/kumamon-asset-check.mjs`（Phase Bで新規）をデプロイ前必須にする

## 禁止事項（特例の条件）

- 改変（色変更・トリミング・CSSフィルタ・文字重ね）禁止
- PWAアイコン・favicon・OGP画像・グッズ的利用は特例の範囲外
- コピーライト「©2010熊本県くまモン#熊本支援」をイラスト直下に必ず表示
