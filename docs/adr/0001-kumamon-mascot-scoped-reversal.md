# ADR-0001: くまモン No-Go 決定の配置条件付き反転

- 日付: 2026-08-01
- 状態: 承認済み（運営者が本日承認）
- 関連: HANDOFF.md:287、docs/DESIGN.md:221、docs/kumamon/README.md

## 文脈

本リポジトリには「キャラクター／アイコン（くまモンは No-Go 確定）。119/110 の導線の隣にマスコットを置かない」（HANDOFF.md:287）、「画像を持たずに識別する。119/110 の隣にマスコットを置かない」（docs/DESIGN.md:221）という決定が記録されている。記録された理由はいずれも「緊急導線の隣にマスコットを置かない」という配置上の懸念である。

2026-07-29、熊本県が「令和8年熊本地震の支援活動におけるくまモンイラスト利用の特例」（届出制・許諾不要）を公開し、支援活動のホームページ等での利用が可能になった（出典: https://www.pref.kumamoto.jp/soshiki/3/274852.html、2026-08-01確認）。前提となる規約状況が変わった。

## 決定

くまモン No-Go を**フッター限定**の条件付きで反転する。

- 掲出位置はトップページのフッターブロック直上（`.safety-note` の後、`<footer>` 免責文の直前）**のみ**。緊急導線（119/110）・困りごとグリッド・アクションカード領域には置かない
- 掲出物はイラスト1点+コピーライト表記+「県の運営・監修ではない」注記。非リンク・無改変
- 緊急縮退モード中は非表示
- PWAアイコン・favicon・OGP画像・グッズ的利用はしない（特例の範囲外）
- 環境変数 `KUMAMON_ENABLED` で数分内に取り下げ可能にする

## 根拠

元決定の理由（緊急導線とマスコットの分離）はフッター限定の掲出でも完全に守られる。反転するのは「くまモンを使わない」という結論部分のみであり、その前提だった規約状況が県の特例公開により変わった。

- HANDOFF.md:287 と docs/DESIGN.md:221 は、掲出実装時（Phase B）に本ADRへの参照付きで更新する
